04 · MODÈLE MATHÉMATIQUE
Suivre une rangée : erreur géométrique → commande
Le contrôleur ne « voit » pas une rangée ; il réduit deux erreurs mesurables.
ẋ = v cos θ    ẏ = v sin θ
Modèle cinématique d’un châssis plan à vitesse v et orientation θ.
ey = yrobot − yrangée
Erreur latérale : distance signée à la ligne de référence.
eθ = wrap(θ − θrangée)
Erreur d’orientation ramenée dans [−π, π].
ω = −kyey − kθeθ
Commande angulaire bornée avant publication sur /cmd_vel.
Traduction dans le code
Le nœud lit la pose ou une estimation issue du LiDAR, calcule les erreurs, applique les gains YAML, puis limite la vitesse pour éviter les oscillations entre rangées.
cruise_speed: 0.45
lateral_gain: 1.20
heading_gain: 0.80
max_angular_z: 0.70
Si le LiDAR perd la rangée, le comportement sûr est de ralentir, conserver la dernière consigne courte, puis déclencher une recherche contrôlée.
Hypothèses : sol localement plan, faible vitesse, centre instantané de rotation au milieu de l’essieu. Les pneus, le glissement et la dynamique complète nécessitent un modèle plus riche.
