Ubuntu 22.04 / ROS 2 Humble

Installer Gazebo, Nav2, RViz2 et Xacro, compiler le workspace, puis lancer Gazebo seul ou l’environnement complet.

INSTALLER
sudo apt install ros-humble-desktop ros-humble-gazebo-ros-pkgs
ros-humble-navigation2 ros-humble-nav2-bringup ros-humble-xacro
01 / BUILDsource /opt/ros/humble/setup.bash
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
02 / GAZEBOros2 launch dog_factory_bringup factory_sim.launch.py
gui:=true navigation:=false
03 / NAV2Ajouter navigation:=true
AMCL + carte + NavFn + DWB + BT Navigator
04 / RVIZ2Fixed Frame: map
Afficher Map, TF, LaserScan, Costmaps, Path
COMMANDE DE DÉMONSTRATION
ros2 launch dog_factory_bringup factory_sim.launch.py gui:=true navigation:=true

FEUILLE DE ROUTE

Passer d’une base de simulation documentée à un système quadrupède physiquement cohérent et évalué expérimentalement.

01 · Contrôleros2_control et contrôleur locomotion quadrupède.
02 · PerceptionCalibration extrinsèque caméra-LiDAR et détection OpenCV/ML.
03 · NavigationSLAM Toolbox, carte réelle et validation d’obstacles inconnus.
04 · RLPPO entraîné, randomisation domaine et transfert Gazebo.
